# Картинки, которые нужно сгенерировать

Игра уже работает без них: фоны тем нарисованы CSS, значок — временный. Эти картинки делают игру красивее,
а значок и обложка нужны для карточек. Генерировать можно в ChatGPT по промптам ниже.

Общие правила для всех картинок: **без текста и букв, без логотипов, без людей, без рамок и скруглённых углов**.

## 1. Фоны тем

Куда класть (после этого пересобрать игру — картинка сама заменит CSS-фон):

```
public/assets/themes/cozy/bg-portrait.webp      1080×1920
public/assets/themes/cozy/bg-landscape.webp     1920×1080
public/assets/themes/sky/bg-portrait.webp
public/assets/themes/sky/bg-landscape.webp
public/assets/themes/sakura/bg-portrait.webp
public/assets/themes/sakura/bg-landscape.webp
```

Формат WebP, до 300 КБ каждая (конвертировать можно на squoosh.app). Игра сама слегка размывает и приглушает фон.
Центр картинки должен быть спокойным: поверх него лежат список слов и буквы. Детали — по краям и углам.

**Уютная (cozy), вертикальная:**

> Вертикальная иллюстрация 1080×1920 для фона мобильной игры со словами. Вид сверху на светлый деревянный стол,
> на нём лист кремовой бумаги. В левом верхнем углу листья комнатного растения, в правом верхнем — чашка чая с паром,
> в левом нижнем — край старой книги. Центр пустой и однотонный. Тёплые кремовые, бежевые и зелёные тона, мягкий утренний свет,
> аккуратный рисованный стиль казуальной игры. Без текста, букв, людей и рамок.

**Уютная, горизонтальная:** тот же промпт, но «Горизонтальная иллюстрация 1920×1080», предметы — по левому и правому краям,
широкая пустая полоса по центру.

**Небо (sky), вертикальная:**

> Вертикальная иллюстрация 1080×1920 для фона мобильной игры. Ясное голубое небо с мягкими пушистыми облаками,
> внизу — крыши и верхние этажи светлых городских домов и кроны деревьев. Центр — чистое небо без деталей.
> Голубые и белые тона, рисованный стиль в духе аниме-пейзажа, спокойное настроение. Без текста, букв, людей и рамок.

**Небо, горизонтальная:** «Горизонтальная иллюстрация 1920×1080», дома и деревья — узкой полосой внизу и по краям.

**Сакура (sakura), вертикальная:**

> Вертикальная иллюстрация 1080×1920 для фона мобильной игры. Весенняя аллея: ветви цветущей сакуры сверху и по бокам,
> внизу — дорожка и деревянная скамейка, в воздухе летят лепестки. Центр светлый и спокойный. Нежно-розовые и кремовые тона,
> мягкий свет, рисованный стиль. Без текста, букв, людей и рамок.

**Сакура, горизонтальная:** «Горизонтальная иллюстрация 1920×1080», ветви — по верхним углам, скамейка — у края.

## 2. Значок приложения

Куда класть: `assets/icon.png`, 1024×1024, без прозрачности. Затем `npm run icons` — команда разложит значок по размерам
для Android и обновит `publish/icon-512.png`. Для Android можно дополнительно положить `assets/icon-foreground.png`
(те же плитки на прозрачном фоне, занимают центральные 60% картинки).

Значок и обложку нельзя делать из скриншотов игры (пункт 5.6 требований Яндекс Игр).

> Квадратная иконка 1024×1024 для мобильной игры со словами. Две объёмные деревянные плитки с округлыми углами лежат
> с небольшим наклоном на кремовом фоне, рядом зелёный лист. Тёплый свет, мягкие тени, стиль казуальной мобильной игры,
> крупные простые формы, хорошо читается в маленьком размере. Плитки без букв. Без текста, без рамки, без скруглённых углов у самой картинки.

После генерации буквы на плитки лучше добавить самому в любом редакторе (например, «С» и «Л»): нейросети часто искажают кириллицу.

## 3. Обложка для Яндекс Игр

Куда класть: `publish/cover.png`. Размер уточните в форме черновика (обычно 800×470).

> Горизонтальная обложка для казуальной игры со словами, соотношение сторон 800×470. В центре россыпь объёмных деревянных плиток,
> вокруг — чашка чая, листья растения, раскрытая книга на светлом деревянном столе. Тёплые кремовые и зелёные тона,
> мягкий утренний свет, рисованный стиль. Слева оставить спокойное место под название. Без текста, букв, людей и рамок.

Название на обложку добавьте в редакторе — оно должно в точности совпадать с названием игры.

## 4. Скриншоты

Генерировать не нужно: `npm run build && npm run screenshots` снимает настоящий геймплей во всех трёх темах
(`publish/screenshots/`). Если консоль просит другой размер: `npm run screenshots -- --portrait=1080x1920 --landscape=1920x1080`.
После замены фонов или названия запустите команду ещё раз.
