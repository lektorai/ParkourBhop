# Чек-лист публикации

Что нужно сделать руками в консолях. Пункты идут по порядку.

## До загрузки (обе площадки)

- [ ] Выбрать название (варианты в DECISIONS.md) и вписать его в `src/config/app.ts`. Проверить, что такого названия
      нет в каталоге Яндекс Игр и в RuStore.
- [ ] По желанию вписать почту для связи в `SUPPORT_EMAIL` (`src/config/app.ts`) — она появится в политике конфиденциальности.
- [ ] Сгенерировать значок, обложку и фоны по ASSETS_TODO.md, положить в папки, выполнить `npm run icons`.
- [ ] Просмотреть `reports/levels.csv`: если какое-то слово не нравится, добавить его в `data/levels-exclude.txt`
      (только бонусное) или `data/blocklist.txt` (запретить совсем) и выполнить `npm run levels`.
- [ ] `npm run check && npm run e2e` — всё зелёное.
- [ ] `npm run build && npm run screenshots` — свежие скриншоты в `publish/screenshots/`.

## Яндекс Игры

Сборка: `npm run build:yandex` → файл `dist/yandex.zip`.

**Черновик**
- [ ] Консоль разработчика → «Добавить игру» → загрузить `dist/yandex.zip`.
- [ ] Название, «Об игре», «Как играть», категории, теги — из `publish/texts-ru.md`. Язык — только русский.
- [ ] Возрастной рейтинг — 0+.
- [ ] Поддерживаемые платформы: компьютер и мобильные устройства. **Телевизоры не отмечать.**
- [ ] Ориентация на мобильных: портретная (игра работает и в альбомной, но рассчитана на портретную).
- [ ] Включить «Игра использует облачные сохранения» (пункт 1.11).
- [ ] Значок, обложка, скриншоты. Размеры указаны прямо в форме; если они отличаются от 1080×1920 и 1920×1080,
      переснять: `npm run screenshots -- --portrait=ШxВ --landscape=ШxВ`.

**Реклама** (вкладка «Реклама»)
- [ ] Подключить монетизацию (Рекламная сеть Яндекса), дождаться подтверждения.
- [ ] Sticky-баннеры: на мобильных в портретной ориентации — «Внизу», на компьютере — включить.
- [ ] Включить «Использовать API для показа sticky-баннера»: без этого покупка «Без рекламы» не сможет скрыть баннер.

**Покупки** (вкладка «Инап-покупки»)
- [ ] Подключить покупки (раздел «Профиль» → Единая лицензионная схема).
- [ ] Завести пять товаров с ID в точности: `no_ads`, `coins_500`, `coins_1500`, `coins_5000`, `themes_all`.
      Названия и описания — из `publish/texts-ru.md`, цены — на ваше усмотрение.
- [ ] Товар, которого нет в консоли или который выключен, игра сама скрывает. Если покупки пока не нужны,
      не заводите ни одного: в магазине останутся только монеты за рекламу.

**Проверка перед отправкой** (кнопка «Открыть с debug-панелью» в черновике)
- [ ] Индикатор загрузчика в левом нижнем углу показывает IT.
- [ ] В панели нет замечаний к Game Ready и разметке геймплея: пройти уровень, открыть окно победы, вернуться в меню.
- [ ] Реклама: «×2 монеты» на окне победы, бесплатные монеты в магазине, полноэкранная после третьего пройденного уровня.
      Во время рекламы музыка молчит, после — игра на том же месте.
- [ ] Тестовая покупка каждого товара: монеты начисляются, «Без рекламы» убирает баннер, после перезагрузки всё на месте.
- [ ] Настройки → «Войти через Яндекс ID»: после входа прогресс тот же; открыть игру на втором устройстве — прогресс совпадает.
- [ ] Свернуть вкладку — музыка замолкает. Перезагрузить страницу посреди уровня — найденные слова на месте.
- [ ] Телефон: повернуть экран, потянуть страницу вниз (не должна обновляться), подержать палец на плитке (нет меню и выделения).
- [ ] Проверить в Яндекс Браузере и Chrome на Android, в Safari на iPhone, в Chrome на компьютере.
- [ ] Консоль браузера (F12) без ошибок за три пройденных уровня.
- [ ] Отправить на модерацию.

## RuStore

Сборка: `npm run build:rustore` → `dist/android/slova-<версия>-nopay-release.aab`. Перед этим — ключ подписи и `.env` по README.

**Реклама**
- [ ] В кабинете Рекламной сети Яндекса добавить Android-приложение (имя пакета — `APP_ID` из `src/config/app.ts`),
      создать два блока: полноэкранный (Interstitial) и с вознаграждением (Rewarded).
- [ ] Вписать их идентификаторы в `.env`: `YANDEX_ADS_INTERSTITIAL_ID`, `YANDEX_ADS_REWARDED_ID`. Пересобрать.

**Приложение**
- [ ] RuStore Консоль → «Добавить приложение». Название — в точности как `APP_NAME` (оно же стоит в APK).
- [ ] Категория, описания, «Что нового» — из `publish/texts-ru.md`. Возрастной рейтинг — 0+.
- [ ] Значок 512×512 (`publish/icon-512.png` после `npm run icons`), скриншоты из `publish/screenshots/portrait/` (не меньше двух).
- [ ] Политика конфиденциальности: RuStore просит ссылку. Текст есть в игре (Настройки → Политика конфиденциальности);
      разместите его на любой своей странице и укажите адрес.
- [ ] Загрузить AAB. Если RuStore попросит объяснить разрешения: `INTERNET` и `ACCESS_NETWORK_STATE` — реклама (и платежи),
      `VIBRATE` — вибрация при нажатиях, `AD_ID` и install referrer добавляет рекламный SDK Яндекса.
      В варианте с покупками Pay SDK дополнительно добавляет `RECEIVE_BOOT_COMPLETED`.
- [ ] В анкете о данных указать: приложение само данные не собирает; рекламный SDK использует рекламный идентификатор.

**Покупки** (только если есть статус ИП или юрлица)
- [ ] Подключить монетизацию в RuStore Консоли.
- [ ] Завести товары: `coins_500`, `coins_1500`, `coins_5000` — потребляемые; `no_ads`, `themes_all` — непотребляемые.
- [ ] В `.env`: `PAYMENTS_ENABLED=true`, `RUSTORE_CONSOLE_APP_ID=<число из адреса приложения>`. Пересобрать — получится `...-pay-release.aab`.
- [ ] Проверить тестовую покупку в режиме песочницы RuStore: монеты начислились, после перезапуска приложения не начислились повторно.

**Проверка на телефоне** (`adb install dist/android/slova-<версия>-...-release.apk`)
- [ ] Включить режим полёта: игра запускается и работает офлайн, реклама за награду вежливо сообщает, что недоступна.
- [ ] Кнопка «Назад»: из уровня — в меню, из меню — диалог выхода.
- [ ] Свернуть и развернуть приложение: музыка замолкает и возвращается, прогресс на месте.
- [ ] Реклама показывается (в отладочной сборке `npm run build:rustore -- --debug` — демо-ролики Яндекса).
- [ ] Перед каждой следующей загрузкой увеличить `APP_VERSION_CODE` в `src/config/app.ts`.
