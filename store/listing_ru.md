# Карточка приложения в RuStore (RU)

Все тексты ниже уложены в лимиты RuStore Консоли: название ≤ 30 символов,
короткое описание ≤ 80, полное ≤ 4000 (ключевое — в первые 2000).

## Название (≤ 30)

```
Японские кроссворды: Нонограммы
```
(30 символов ровно; запасной вариант — `Японские кроссворды офлайн`)

## Короткое описание (≤ 80)

```
Бесконечные японские кроссворды офлайн: уровни 5×5–15×15, картинки, задача дня
```

## Полное описание (≤ 4000)

```
Японские кроссворды (нонограммы) — спокойная логическая головоломка, в которой по числам у строк и столбцов вы закрашиваете клетки и открываете скрытую картинку.

ЧТО ВНУТРИ
• Бесконечные уровни трёх размеров: 5×5 для разминки, 10×10 классика и 15×15 для экспертов. Каждый кроссворд генерируется так, что решается чистой логикой — без угадывания.
• Головоломка дня — новый кроссворд каждый день и серия дней за ежедневные решения.
• Галерея картинок — 38 нарисованных вручную нонограмм: сердце, котик, домик, сова, парусник, панда и другие. Решите, чтобы открыть картинку.
• Удобное управление: нажмите, чтобы закрасить, проведите пальцем — заполнить линию. Режим «крестик», отмена хода, авто-крестики в готовых линиях.
• Подсказки, когда застряли, и проверка ошибок (можно отключить для режима «как на бумаге»).
• Звёзды за аккуратное решение, статистика, лучшее время, серия дней.
• Тёмная тема, русский и английский языки.

ПОЛНОСТЬЮ ОФЛАЙН
Играйте где угодно: в метро, в дороге, на даче. Интернет не нужен, прогресс сохраняется автоматически, недорешённый кроссворд можно продолжить в любой момент.

ДЛЯ КОГО
Для тех, кто любит судоку, кроссворды, пиксельные головоломки и «японские сканворды». Простые правила, которые осваиваются за минуту, и глубина, которой хватит на месяцы.

КАК ИГРАТЬ
Числа слева от строки и сверху над столбцом показывают длины закрашенных блоков по порядку. Между блоками всегда есть хотя бы одна пустая клетка. Сопоставляйте строки и столбцы, отмечайте крестиками клетки, которые точно пусты, и картинка проявится сама.

Пишите нам, если нашли ошибку или хотите новую картинку в галерее — мы читаем каждый отзыв.
```

## Категория и возраст

- Категория: **Игры → Головоломки**
- Возрастная категория: **0+**
- Маркеры контента (игры): без насилия, без азартных игр

## Разрешения и безопасность данных (раздел «Безопасность данных»)

Базовая сборка (без рекламного SDK): приложение не собирает и не передаёт
данные, сетевых разрешений нет. Разрешение VIBRATE — для тактильного отклика.

После подключения Яндекс Рекламы: укажите сбор «Идентификаторы устройства /
рекламный ID» и «Данные об использовании» → «Для показа рекламы», а также
разрешения INTERNET и ACCESS_NETWORK_STATE.

## Медиа

- Иконка 512×512 без прозрачности: `store/icon_512.png`.
- Скриншоты телефона: `store/screenshots/ru/*.png` (720×1280, портрет).
  Для RuStore подойдут как есть (PNG, < 3 МБ, ≤ 2160×3840). При желании
  перегенерируйте в 1080×1920: `xvfb-run -a -s "-screen 0 1080x1920x24" godot --path . --rendering-driver opengl3 --script tools/screenshots.gd`.
- Английские скриншоты: `SCREENSHOT_LOCALE=en` при запуске того же скрипта.
